
# 마음전서구 DB 설계 매뉴얼

안녕하세요! 마음전서구 프로젝트의 DB 설계를 돕기 위해 이 매뉴얼을 작성했습니다. 

## 1. DB 기본 개념

DB(데이터베이스)는 쉽게 말해 **정보를 체계적으로 저장하고 관리하는 공간**입니다. 엑셀 시트처럼 표(Table) 형태로 데이터를 정리한다고 생각하면 이해하기 쉽습니다.

*   **테이블(Table):** 특정 주제에 대한 데이터의 집합입니다. (예: `users`, `gifts`, `questions`)
*   **필드(Field) 또는 컬럼(Column):** 테이블의 각 열을 의미하며, 데이터의 속성을 나타냅니다. (예: `users` 테이블의 `user_id`, `name`, `age`)
*   **레코드(Record) 또는 로우(Row):** 테이블의 각 행을 의미하며, 실제 데이터 하나하나를 나타냅니다. (예: `users` 테이블의 1번 유저 '홍길동', 25세)
*   **기본 키(Primary Key, PK):** 각 레코드를 고유하게 식별할 수 있는 값입니다. (예: `user_id`)
*   **외래 키(Foreign Key, FK):** 다른 테이블의 기본 키를 참조하여 테이블 간의 관계를 맺어주는 값입니다.

## 2. 마음전서구 DB 설계 초안 (JSON)

JSON(JavaScript Object Notation)은 사람이 읽고 쓰기 쉬운 데이터 교환 형식입니다. 웹 애플리케이션에서 데이터를 주고받을 때 많이 사용됩니다.

### `gifts.json` (선물 데이터)

선물 정보를 담는 파일입니다.

```json
[
  {
    "gift_id": 1,
    "category": "실용형",
    "sub_category": "의류",
    "brand": "유니클로",
    "product_name": "에어리즘 코튼 오버사이즈 크루넥T",
    "price": 19900,
    "tags": ["#데일리", "#편안함", "#가성비"],
    "image_url": "image_url_here"
  },
  {
    "gift_id": 2,
    "category": "취향형",
    "sub_category": "주류",
    "brand": "탈리스커",
    "product_name": "탈리스커 10년",
    "price": 75000,
    "tags": ["#위스키", "#피트", "#싱글몰트"],
    "image_url": "image_url_here"
  }
]
```

### `questions.json` (심리테스트 질문 데이터)

심리테스트의 질문과 답변을 담는 파일입니다.

```json
[
  {
    "question_id": 1,
    "question_text": "선물받을 그 사람이 가장 먼저 할 말은?",
    "answers": [
      {
        "answer_id": 1,
        "answer_text": ""와, 이거 완전 내 취향인데?"",
        "score": { "취향형": 3, "감성형": 1 }
      },
      {
        "answer_id": 2,
        "answer_text": ""오, 이거 어떻게 알았어? 딱 필요했는데!"",
        "score": { "실용형": 3, "취향형": 1 }
      },
      {
        "answer_id": 3,
        "answer_text": ""네가 나를 위해 준비했다는 마음이 더 소중해."",
        "score": { "감성형": 3, "경험형": 1 }
      },
      {
        "answer_id": 4,
        "answer_text": ""다음에 같이 쓰면 좋겠다!"",
        "score": { "경험형": 3, "실용형": 1 }
      }
    ]
  }
]
```

### `letter_templates.json` (편지 템플릿)

편지 생성에 사용될 템플릿입니다.

```json
[
  {
    "template_id": 1,
    "tone": "다정한",
    "occasion": "생일",
    "template": "{recipient_name}에게,

생일 진심으로 축하해! 🎉

{sender_name}이(가) 너를 얼마나 생각하는지, 이 편지에 고스란히 담겨있어. 너는 {user_trait} 사람이라, {gift_category} 선물이 잘 어울릴 것 같았대. 이 선물이 너의 일상에 작은 기쁨이 되었으면 좋겠다.

앞으로도 우리 우정 변치 말자!

사랑을 담아,
{sender_name}"
  }
]
```

## 3. DB 활용 방안 (간단한 로직)

1.  **심리테스트 진행:**
    *   `questions.json`에서 질문을 순서대로 가져와 사용자에게 보여줍니다.
    *   사용자가 답변을 선택하면, 해당 답변의 `score`를 기록합니다.
2.  **결과 분석:**
    *   모든 질문에 대한 답변이 끝나면, 각 유형(`실용형`, `취향형` 등)의 점수를 합산합니다.
    *   가장 높은 점수를 받은 유형이 추천 선물 카테고리가 됩니다.
3.  **선물 추천:**
    *   `gifts.json`에서 해당 카테고리의 선물들을 필터링하여 보여줍니다.
    *   사용자의 예산, 관계 등을 추가로 고려하여 추천 순위를 정할 수 있습니다.
4.  **편지 생성:**
    *   결과 분석을 통해 얻은 정보(가장 높은 점수 유형, 사용자가 선택한 답변 내용 등)를 `letter_templates.json`의 템플릿에 채워 넣어 편지를 완성합니다.
