< 프로젝트 기획서 : 선물 추천 및 편지 자동작성 앱 >				
작성일자	2025-07-19			
기간	1개월 (심리테스트 웹버전 데모까지)			
인원	개인작업			
가제	마음전서구 : 마음을 전하는 서너가지 구성품 (Heart Pigeon)			
기획 배경	"1. 타인이 좋아하는 선물 고르기의 어려움.
2. 선물 받을 사람에게 직접 원하는 선물을 물어보면 에둘러 말하는 한국식 겸양 문화.
3. 기존 선물 고르는 심리테스트의 결과물이 제한적임.
 - 문항과 질문의 양식이 정적이며, 4 ~ 10가지의 결과로 수렴한다."			
기획 목표	"1. 인터넷 사용자들에게 익숙한 심리테스트, 설문조사, 랜덤박스, 기프티콘 증정 형식으로 선물 퍼센테이지 추천.
2. 선물 선택 과정의 정성을 측량 및 기록하여 선물 받는 사람에게 편지 등 텍스트 형식으로 전달.
3. (심리테스트 경우) 답안을 선택할 때 다음 질문이 결정되는 시스템으로, 동적 데이터(사용자, 선물받을사람)와 정적 데이터(선물 추천식)를 결합해 높은 상호작용 경험 제공."			
기획 효과	"1. 받는 사람에 관한 상세한 편지를 통해, 선물하는 사람과 받는 사람간의 관계 증진.
2. 선물을 하는 것보다, 상대를 명확히 아는 것이 더 중요하다는 사용자 경험 제공.
3. 글로벌 판매 가능한 한국 제품을 다수 투입하여, 스코빌이라는 명칭에 걸맞은 행보 보이기."			
주요 기능	"1. 로그인 동기화 기능
2. ★선물할 상대에 관한 심리테스트 기능
3. 선물할 상대에 관한 설문조사 기능
4. 선물 뽑는 랜덤박스 플레이 기능
5. 기프티콘 추천 기능
6. ★2~4번 결과에 따른 선물 퍼센테이지 추천 기능
7. ★2~5번 결과에 따른 편지, 엽서 등 텍스트 자동완성기능
8. 세션 보관 기능"			
주요 고객	"1. 본인이 트렌드에 민감하다고 믿지만, 선물 감각이 떨어지는 10~30대 여성
2. 1번의 공유를 통해 브랜드를 알게 된 여성 지인
3. 1번의 공유를 통해 브랜드를 알게 된 커플 남성"			

heartpigeon_develop(기획안 초안)

◎ 타이틀 
마음전서구 (Heart Pigeon)
마음을 전하는 서넛의 구성품이라는 뜻
선물 보내는 사람과 받는 사람 기반의 설문/심리테스트로 에디터 기능 추가한 선물 브랜드

◎ 콘셉트 
선물을 고르기 위한 과정의 정성을 ‘측량’하고 ‘기록’하여 선물 받는 사람에게 전서구 형태로 보내줌.
1. 선물하는 사람이 선물받는 사람에 관한 심리테스트하기(정순)
2. 선물 받는 사람이 본인에 관한 심리테스트하고, 그 결과를 선물하는 사람에게 전달하기(역순)

◎ 콘텐츠
심리테스트형 : 사지선다 총 열 문항의 심리테스트 진행. 내용 반영해서 편지 써주고 추천 선물 골라줌.
(ex : 
1. 실용형 Practical
일상적으로 쓰고 도움이 되는 실물
예: 의류, 위생용품, 건강기능식품, 전자기기, 다이어리, 가방, 양말
🎯 특징: 용도 기반 추천 가능 ("쓸모 있는 선물 원해요")
2. 취향형 Tasteful
향유·즐김을 위한 아이템, 취미+감성+감각
예: 위스키, 디저트, 원두, 올리브오일, 책, 시가, 아트북, 향수
🎯 특징: "그 사람의 취향" 기반으로 추천 가능
3. 감성형 Emotional
추억·감정·감동 중심의 선물
예: 손편지, 포토북, 캘리그라피 엽서, 커플 아이템, 편지와 꽃, DIY 키트
🎯 특징: 관계와 연결됨 ("기념일", "사랑 표현")
4. 경험형 Experiential
실물이 아닌, 경험을 선물하는 형태
예: 전시/공연 티켓, 클래스 쿠폰, 마사지 이용권, 숙박권, 액티비티 예약
🎯 특징: 시간/장소 의존, 추천 시 타이밍 중요

1차 질문 : 대분류 선택
2차 질문 : 중분류 1단계
3차 질문 : 중분류 2단계
4차 질문 : 

설문조사형 : 약 30문항의 조사한 것 기록해서 보고서 형식으로 선물 받는 사람의 정보를 출력. 얼마나 생각하는지 알려줌. 
(ex : 익명의 하마님에 대해 조사한 보고서입니다. 당신은 보기보다 내향형 인간이며, 혼술을 좋아하고 인테리어에 관심이 많습니다... 추천하는 선물 리스트 : 탈리스커 18년 54%, 르코르뷔지에 벽조명 32%,..)
랜덤박스형 : 뽑은 로그 반영해서 노력을 집산하여 데이터 출력함.
☆기프티콘형(일주일에 1~2일 오픈) 기프티콘 구매하면 세션 확인하여 축약된 편지 로그 입력해줌.
