# 피그마(Figma) 컴포넌트 및 프로토타입 기능 매뉴얼

피그마의 컴포넌트(Component)와 프로토타입(Prototype) 기능을 활용하면 디자이너와 기획자가 실제 동작하는 것처럼 보이는 인터랙티브한 목업(Mockup)을 손쉽게 제작할 수 있습니다. 이 매뉴얼은 해당 기능의 핵심 개념과 사용법을 안내합니다.

## 1. 컴포넌트(Components)란?

컴포넌트는 UI에서 재사용할 수 있는 디자인 요소입니다. 예를 들어 버튼, 아이콘, 입력 필드, 내비게이션 바 등을 컴포넌트로 만들 수 있습니다.

- **Main Component (메인 컴포넌트):** 컴포넌트의 원본입니다. 메인 컴포넌트를 수정하면 모든 인스턴스에 변경 사항이 즉시 반영됩니다.
- **Instance (인스턴스):** 메인 컴포넌트의 복사본입니다. 인스턴스는 메인 컴포넌트의 속성을 상속받지만, 텍스트나 색상 등 일부 속성은 개별적으로 수정할 수 있습니다(Override).

### 컴포넌트 생성 방법

1.  재사용할 디자인 요소(객체 또는 그룹)를 선택합니다.
2.  상단 툴바의 다이아몬드 모양 아이콘(Create Component)을 클릭하거나, 단축키 `Ctrl + Alt + K`를 누릅니다.
3.  선택한 요소가 보라색으로 변하며 메인 컴포넌트로 지정됩니다.

## 2. 베리언트(Variants)란?

베리언트는 하나의 컴포넌트가 가질 수 있는 다양한 상태나 스타일을 그룹화한 것입니다. 예를 들어, 버튼 컴포넌트는 `default`, `hover`, `pressed`, `disabled`와 같은 여러 상태를 가질 수 있습니다. 베리언트를 사용하면 이러한 상태들을 하나의 컴포넌트 내에서 체계적으로 관리할 수 있습니다.

### 베리언트 생성 및 활용

1.  상태별로 다른 디자인을 가진 여러 개의 컴포넌트를 만듭니다. (예: 기본 상태 버튼, 마우스 오버 상태 버튼)
2.  생성한 컴포넌트들을 모두 선택합니다.
3.  오른쪽 디자인 패널에서 **'Combine as variants'** 버튼을 클릭합니다.
4.  이제 하나의 컴포넌트 세트가 생성되며, 오른쪽 패널에서 각 베리언트의 속성(Property)을 정의하고 값을 설정할 수 있습니다. (예: Property: `State`, Values: `default`, `hover`)

## 3. 프로토타입(Prototyping) 기능과 연동하기

컴포넌트와 베리언트를 만들었다면, 이제 프로토타입 기능을 통해 상호작용을 추가할 차례입니다.

### 인터랙티브 컴포넌트 만들기 (예: 호버 버튼)

1.  **베리언트 준비:** `default` 상태와 `hover` 상태를 가진 버튼 컴포넌트 베리언트를 준비합니다.
2.  **프로토타입 모드 전환:** 화면 오른쪽 상단의 **'Prototype'** 탭을 클릭합니다.
3.  **인터랙션 추가:**
    *   `default` 상태의 버튼 베리언트를 선택합니다.
    *   객체 오른쪽에 나타나는 파란색 `+` 핸들을 클릭하여 드래그한 뒤, `hover` 상태의 버튼 베리언트에 연결합니다.
    *   **Interaction details** 팝업창이 나타납니다.
    *   트리거(Trigger)를 **'While hovering'** (마우스를 올렸을 때)으로 설정합니다.
    *   액션(Action)은 자동으로 **'Change to'**로 설정되며, 대상은 `hover` 상태의 버튼으로 지정됩니다.
4.  **확인:** 이제 이 버튼 컴포넌트의 인스턴스를 프레임에 배치하고 프로토타입을 실행(상단 오른쪽의 'Present' 버튼)하면, 마우스를 올렸을 때 버튼 디자인이 바뀌는 것을 확인할 수 있습니다.

## 간단한 실습: ON/OFF 토글 스위치 만들기

1.  **디자인:** 'OFF' 상태와 'ON' 상태의 토글 스위치 디자인을 각각 만듭니다.
2.  **컴포넌트 생성:** 두 디자인을 각각 컴포넌트로 만듭니다.
3.  **베리언트 결합:** 두 컴포넌트를 선택하고 'Combine as variants'를 실행합니다.
4.  **프로토타입 인터랙션 설정:**
    *   'OFF' 상태 베리언트를 선택하고, 프로토타입 핸들을 'ON' 상태로 연결합니다.
    *   Interaction details에서 트리거를 **'On click'** (클릭했을 때)으로 설정합니다.
    *   'ON' 상태 베리언트도 마찬가지로 'OFF' 상태로 'On click' 인터랙션을 추가합니다.
5.  **완성:** 프레임에 토글 스위치 인스턴스를 놓고 프로토타입을 실행하면, 클릭할 때마다 ON/OFF 상태가 바뀌는 것을 볼 수 있습니다.
