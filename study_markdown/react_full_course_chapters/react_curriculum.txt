### React 교육 커리큘럼

**[완료된 과정]**

1.  **JSX와 컴포넌트**: React의 기본 문법과 컴포넌트 기반 구조 학습
2.  **Props**: 컴포넌트 간의 데이터 전달 방법 학습
3.  **State와 생명주기**: `useState`와 `useEffect`를 사용한 상태 관리 및 생명주기 제어
4.  **이벤트 핸들링**: 사용자 인터랙션 처리 방법 학습
5.  **조건부 렌더링**: 특정 조건에 따라 다른 UI를 보여주는 방법
6.  **리스트와 Key**: 배열 데이터를 렌더링하고 `key`의 중요성 학습
7.  **폼 다루기**: 사용자 입력을 받는 폼 요소 제어
8.  **Hooks 심화**: `useContext`, `useReducer`, `useCallback`, `useMemo` 등 심화 훅 학습
9.  **스타일링**: CSS, CSS-in-JS 등 다양한 스타일링 방법
10. **React Router**: 페이지 라우팅 및 SPA 구현
11. **전역 상태 관리**: `Zustand`를 이용한 간편한 전역 상태 관리
12. **최종 프로젝트 (진행 중)**
    *   1단계: 프로젝트 구조 설정 (폴더 및 파일 생성)
    *   2단계: `react-router-dom`을 이용한 라우터 설정

**[진행할 과정]**

1.  **최종 프로젝트 (계속)**
    *   **3단계: 페이지 구현**
        *   `PostListPage`: Zustand 스토어의 게시글 목록을 가져와 화면에 렌더링
        *   `PostDetailPage`: 특정 게시글의 상세 내용 표시 및 수정/삭제 기능 연결
        *   `EditPostPage`: 기존 게시글의 내용을 수정하는 폼 구현
    *   **4단계: 기능 완성 및 배포**
        *   전체 기능 검토 및 버그 수정
        *   빌드 및 배포 과정 안내
