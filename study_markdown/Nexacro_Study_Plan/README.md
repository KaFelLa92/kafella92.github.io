# 넥사크로(Nexacro) 학습 로드맵 (for Spring/React 개발자)

안녕하세요! 이 학습 계획은 Spring, React 등 다른 프레임워크 경험이 있는 개발자분들이 넥사크로에 빠르게 적응할 수 있도록 설계되었습니다.

걱정하시는 것과 달리, 넥사크로는 공식 한글 문서와 자료가 매우 잘 갖춰져 있어 학습하기 좋은 환경을 제공합니다.

이 로드맵을 따라 차근차근 진행하시면, 3주 안에 넥사크로로 간단한 CRUD 애플리케이션을 만들고 서버와 통신하는 수준까지 충분히 도달하실 수 있습니다.

## 학습 구조

- **[1주차: 입문 및 핵심 개념](./Week_1/):** 넥사크로와 친해지기
- **[2주차: 데이터 처리 및 통신](./Week_2/):** 넥사크로의 심장 이해하기
- **[3주차 이후: 실전 프로젝트](./Week_3_and_beyond/):** 직접 만들어보며 체득하기

각 폴더의 마크다운 파일들을 순서대로 학습하시는 것을 권장합니다.

그럼, 시작하겠습니다!
